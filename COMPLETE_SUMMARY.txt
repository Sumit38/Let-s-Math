🎯 INSTALLATION & TESTING PATHS
═══════════════════════════════════════════════════════════════════════════════

  PATH A: Install on Physical Phone/Tablet
  ──────────────────────────────────────────

    1. Build APK (see Quick Start above)
    2. Copy app-debug.apk to phone (USB or email)
    3. Open file manager on phone
    4. Tap APK file
    5. Tap "Install"
    6. Open app from home screen


  PATH B: Test on Android Emulator (from Android Studio)
  ────────────────────────────────────────────────────

    1. In Android Studio: Run → Run 'app'
    2. Select an Android Virtual Device
    3. Click OK
    4. App builds and runs automatically


  PATH C: Quick Test from Android Studio (fastest)
  ────────────────────────────────────────────────

    1. Connect phone via USB
    2. Enable USB Debugging (Settings → Developer Options)
    3. Run → Run 'app'
    4. Select your device
    5. Click OK
    6. App installs and opens automatically

📦 BUILD TYPES FOR DIFFERENT PURPOSES
═══════════════════════════════════════════════════════════════════════════════

  DEBUG APK (Testing)
  ──────────────────
  How: Build → Build APK(s)
  Size: ~60 MB
  Location: app/build/outputs/apk/debug/app-debug.apk
  Use: Testing on devices, development
  Signing: Automatic (debug key)


  RELEASE APK (Distribution via Direct Download)
  ──────────────────────────────────────────────
  How: Build → Generate Signed Bundle / APK → Select APK
  Size: ~60 MB (can be optimized)
  Location: app/build/outputs/apk/release/app-release.apk
  Use: Email, website download, direct distribution
  Signing: Your keystore (save it!)


  APP BUNDLE (Play Store Submission)
  ──────────────────────────────────
  How: Build → Generate Signed Bundle / APK → Select Bundle
  Size: ~50 MB (compressed)
  Location: app/build/outputs/bundle/release/app-release.aab
  Use: Google Play Store
  Signing: Your keystore (save it!)

🔐 RELEASING TO GOOGLE PLAY STORE
═══════════════════════════════════════════════════════════════════════════════

  1. Build App Bundle
     • Build → Generate Signed Bundle / APK
     • Select "Android App Bundle"
     • Create keystore (save safely!)
     • Follow signing wizard
     • Bundle ready in: app/build/outputs/bundle/release/


  2. Create Play Store Account
     • Go to: https://play.google.com/console
     • Sign in with Google Account
     • Pay $25 one-time fee


  3. Create App Listing
     • Create new app
     • Fill in app name, description, category
     • Add screenshots and icons
     • Write description


  4. Upload Bundle
     • Go to: Release → Create new release
     • Upload AAB file
     • Add release notes


  5. Set Pricing & Distribution
     • Choose: Free or Paid
     • Select countries


  6. Review & Publish
     • Fill content rating questionnaire
     • Review policies
     • Click "Publish"


  🎉 App goes live in Google Play Store!

🆘 TROUBLESHOOTING QUICK REFERENCE
═══════════════════════════════════════════════════════════════════════════════

  "Gradle sync fails"
    → File → Project Structure → Set SDK paths → OK


  "Can't find JDK"
    → File → Project Structure → Set JDK location → OK


  "Can't find Android SDK"
    → Tools → Device Manager (auto-triggers SDK setup)


  "Build fails"
    → Build → Clean Project → Build → Rebuild Project


  "APK won't install"
    → Device must be Android 5.0+
    → Enable "Unknown Sources" in Settings


  "App crashes"
    → Clear app data: Settings → Apps → Let's Math → Clear Data
    → Reinstall


  More help → See LetsMatApp/IMPORT_GUIDE.txt

💡 TIPS & BEST PRACTICES
═══════════════════════════════════════════════════════════════════════════════

  ✓ First build takes longer (downloading dependencies)
  ✓ Subsequent builds are much faster
  ✓ Physical device testing is faster than emulator
  ✓ Save keystore file safely (needed for app updates)
  ✓ Test on multiple devices before release
  ✓ Use APK for direct distribution, Bundle for Play Store
  ✓ Don't lose keystore password!
  ✓ Keep keystores organized for multiple apps
