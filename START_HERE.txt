└─────────────────────────────────────────────────────────────────────────────┘

  STEP 1: Install Dependencies (First Time Only)
  ──────────────────────────────────────────────

    Open Command Prompt and run:

    cd "C:\Users\sumit.haldar\Let's Math V 1.2"
    npm install

    ⏱️  Takes about 5-10 minutes


  STEP 2: Build for Android
  ─────────────────────────

    cd "C:\Users\sumit.haldar\Let's Math V 1.2"
    npm run build
    npm run android:add
    npm run sync
    npm run android:open

    ⏱️  Takes about 15-20 minutes
    ✅ Opens Android Studio automatically


  STEP 3: Build APK in Android Studio
  ────────────────────────────────────

    • Wait for Gradle sync to finish
    • Go to: Build → Build Bundle(s) / APK(s) → Build APK(s)
    • Wait for completion
    • APK ready in: android/app/build/outputs/apk/debug/app-debug.apk

    ⏱️  Takes 2-5 minutes
    ✅ Ready to test on device!

┌─────────────────────────────────────────────────────────────────────────────┐
│  📝 TO ADD OR EDIT CONTENT                                                  │
└─────────────────────────────────────────────────────────────────────────────┘

  All content is in: src/data.js

  To add a new chapter:
    1. Open src/data.js
    2. Add new object to the chapters array
    3. Include: id, section, title, icon, concept, workingExample, tricks, practice
    4. Save file
    5. Run: npm run build && npm run sync
    6. Rebuild APK

  No need to touch any other files!

┌─────────────────────────────────────────────────────────────────────────────┐
│  🆘 QUICK TROUBLESHOOTING                                                   │
└─────────────────────────────────────────────────────────────────────────────┘

  "npm: command not found"
    → Install Node.js from https://nodejs.org/

  "java: command not found"
    → Install JDK from https://www.oracle.com/java/technologies/downloads/

  "Changes not showing in app"
    → Always run: npm run build && npm run sync

  "APK won't install on phone"
    → Device must be Android 7.0+
    → Enable "Unknown Sources" in Settings

  More help → QUICK_START.md troubleshooting section
