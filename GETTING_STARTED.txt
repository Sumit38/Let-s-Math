PATH A: Test in Browser First (Recommended for Windows users)
────────────────────────────────────────────────────────────

1. Open Command Prompt or PowerShell
2. Navigate to: C:\Users\sumit.haldar\Let's Math V 1.2
3. Run these commands:

   cd "C:\Users\sumit.haldar\Let's Math V 1.2"
   npm install
   npm start

4. Browser opens automatically at http://localhost:3000
5. Test the app - click chapters, mark confidence, check progress
6. Once happy with content, proceed to Path B

PATH B: Build Android APK (Direct Path)
────────────────────────────────────────

Prerequisites (verify these work):
  • Java: Open Command Prompt, type: java -version
  • Node.js: Open Command Prompt, type: npm --version
  • Android Studio installed

Steps:
  cd "C:\Users\sumit.haldar\Let's Math V 1.2"
  npm install
  npm run build
  npm run android:add
  npm run sync
  npm run android:open

  → Android Studio opens with your project
  → Build → Build APK(s)
  → Wait for completion
  → APK ready in android/app/build/outputs/apk/debug/app-debug.apk

2. TEST LOCALLY (Optional but recommended)

3. BUILD REACT

   npm run sync

   → Transfer to phone and install

❓ TROUBLESHOOTING:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

"npm: command not found"
→ Install Node.js from https://nodejs.org/
→ Restart terminal

"java: command not found"
→ Install JDK from https://www.oracle.com/java/technologies/downloads/
→ Restart terminal

"Gradle sync failed"
→ See QUICK_START.md troubleshooting section

"APK won't install"
→ Phone must be Android 7.0+
→ Enable "Unknown Apps" in settings
→ Clear app cache

More troubleshooting → See QUICK_START.md
