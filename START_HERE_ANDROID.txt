📱 TESTING YOUR APP
════════════════════════════════════════════════════════════════════════════════

  Option A: On Your Phone (FASTEST - Recommended)
  ────────────────────────────────────────────────

    1. Connect phone via USB
    2. On phone: Settings → About Phone → tap "Build Number" 7 times
    3. Go back to Settings → Developer Options → USB Debugging ON
    4. In Android Studio: Run → Run 'app'
    5. Select your phone
    6. Click OK
    7. App installs and runs automatically!


  Option B: Copy APK to Phone
  ──────────────────────────

    1. Build APK (see Quick Start above)
    2. Copy the APK file
    3. Paste on your phone storage
    4. Open file manager on phone
    5. Tap the APK file
    6. Tap "Install"
    7. Open app from home screen


  Option C: Android Emulator (in Android Studio)
  ──────────────────────────────────────────────

    1. Run → Run 'app'
    2. Select Android Virtual Device (or create one)
    3. Click OK
    4. Wait for emulator to boot
    5. App installs and runs

🆘 TROUBLESHOOTING (If Something Goes Wrong)
════════════════════════════════════════════════════════════════════════════════

  Problem: Can't open folder in Android Studio
  Solution: Use absolute path from Quick Start above

  Problem: Gradle sync fails
  Solution:
    • File → Project Structure
    • Set Android SDK & Java paths
    • Try again

  Problem: Build fails
  Solution:
    • Build → Clean Project
    • Build → Rebuild Project

  Problem: App won't install
  Solution:
    • Phone must be Android 5.0+
    • Enable "Unknown Sources" in Settings

  Problem: App crashes
  Solution:
    • Clear app data on phone
    • Reinstall

  For more help → See README_ANDROID.txt
