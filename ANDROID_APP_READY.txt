🆘 QUICK TROUBLESHOOTING

  Problem: Gradle sync fails
  Solution:
    • File → Project Structure
    • SDK Location: Set correct Android SDK and JDK paths
    • Try again

  Problem: Can't find Android SDK
  Solution:
    • Tools → Device Manager (triggers SDK setup)
    • Install API 34 when prompted

  Problem: App won't build
  Solution:
    • Build → Clean Project
    • Build → Rebuild Project

  Problem: APK won't install
  Solution:
    • Device must be Android 5.0+
    • Enable "Unknown Sources" in device settings

  Problem: App crashes on startup
  Solution:
    • Phone Settings → Apps → Let's Math → Storage → Clear Data
    • Reinstall APK
