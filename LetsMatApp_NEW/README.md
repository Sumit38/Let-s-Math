# Let's Math - Android App

Complete Android app with React-based math learning platform.

## Quick Start

1. Open this folder in Android Studio: `File → Open → Select this folder`
2. Wait for Gradle sync to complete (bottom right)
3. Click `Build → Build Bundle(s) / APK(s) → Build APK(s)`
4. Wait for success message
5. APK location: `app/build/outputs/apk/debug/app-debug.apk`

## Build for Play Store

1. Click `Build → Generate Signed Bundle / APK`
2. Select `Android App Bundle`
3. Create keystore (save password!)
4. Bundle location: `app/build/outputs/bundle/release/app-release.aab`

## Features

✓ 16 Math Chapters
✓ Tricks & Shortcuts
✓ Predicted Questions
✓ Progress Tracking
✓ Offline Support

## Requirements

- Android Studio
- Java 11+
- 4GB RAM
- 2GB disk space
