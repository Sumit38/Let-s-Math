# Let's Math — Android Studio Project

A ready-to-open Android Studio project. It wraps a self-contained web app
(HTML/CSS/JS, no external build tools needed) inside a native Android
WebView, so it installs and runs like a normal app.

## How to build the APK

1. Install **Android Studio** (free): https://developer.android.com/studio
2. Delete any old unzipped copy of this project first (avoid stale-file conflicts).
3. Open Android Studio → **File > Open** → select this `LetsMath` folder.
4. Let it sync (first open may download Gradle/SDK bits — needs internet).
5. **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
6. Find the APK at `app/build/outputs/apk/debug/app-debug.apk`, copy it to
   your phone, and tap to install (allow "install from unknown sources" once).

## To test instantly without building an APK

Open `app/src/main/assets/index.html` directly in any browser.

## What's in this version

- **Full syllabus, all 16 chapters populated** — concept, worked example
  (many pulled directly from real recurring question types found in your
  uploaded 2019/2020 papers), a live graph, and practice Q&A with
  tap-to-reveal answers.
- **Exam Pattern tab** — real marks structure (100 total: 80 compulsory +
  20 choice) pulled from your uploaded papers.
- **Tricks tab (new)** — quick-recall shortcuts for every chapter, written
  for last-minute exam revision. Tap any chapter to expand.
- **2027 Predicted tab (new)** — practice questions with full worked
  solutions, generated by analysing recurring topics/formats/marks across
  your uploaded 2014–2024 papers. Clearly labelled as pattern-based
  predictions, not official or leaked questions.
- **Progress tracking (new)** — each chapter has a "Still learning /
  Practicing / Confident" self-rating, saved on the device (via
  localStorage inside the WebView) and reflected in a progress bar on
  Home. No accounts, no server, fully private to the device.
- **UI pass** — chapter icons, a rotating mindset/encouragement banner on
  Home, and general visual polish aimed at making the whole thing feel
  approachable rather than intimidating.

## Project structure

```
LetsMath/
├── build.gradle
├── settings.gradle
├── gradle.properties
├── gradlew, gradlew.bat, gradle/wrapper/  (Gradle wrapper — required for sync)
└── app/
    ├── build.gradle
    └── src/main/
        ├── AndroidManifest.xml
        ├── java/com/letsmath/iscprep/MainActivity.kt   (WebView host)
        ├── res/values/strings.xml, themes.xml
        └── assets/index.html     (the entire app lives here)
```

To add or edit content later, everything is in `assets/index.html`:
`chapterContent` (concepts/examples/practice), `trickContent` (the Tricks
tab), and `predictedQuestions` (the 2027 tab) are plain JS objects near
the top of the `<script>` block.
