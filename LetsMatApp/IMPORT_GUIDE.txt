  STEP 1: Open in Android Studio
  ────────────────────────────────

    1. Download Android Studio from:
       https://developer.android.com/studio

    2. Open Android Studio

    3. Click: File → Open

    4. Browse to: C:\Users\sumit.haldar\Let's Math V 1.2\LetsMatApp

    5. Click: Open

    6. Wait: Gradle sync to complete (bottom right, should say "Gradle sync finished")


  STEP 2: Wait for Gradle Sync
  ────────────────────────────

    • You'll see progress at the bottom right
    • Wait for: "Gradle sync finished" message
    • This takes 2-5 minutes (first time)


  STEP 3: Build APK
  ─────────────────

    1. Go to: Build → Build Bundle(s) / APK(s) → Build APK(s)

    2. Wait: "BUILD SUCCESSFUL" message appears

    3. Find APK: LetsMatApp/app/build/outputs/apk/debug/app-debug.apk


  STEP 4: Run on Device
  ────────────────────

    Option A: On Android Phone/Tablet
    ──────────────────────────────────
      1. Connect device via USB
      2. Enable Developer Mode:
         • Settings → About Phone
         • Tap "Build Number" 7 times
         • Back to Settings → Developer Options → USB Debugging: ON
      3. In Android Studio: Run → Run 'app'
      4. Select your device → OK
      5. Wait for app to install and run

    Option B: On Emulator
    ────────────────────
      1. In Android Studio: Tools → Device Manager
      2. Create a virtual device if needed
      3. Run → Run 'app'
      4. Select emulator → OK
      5. Wait for app to run


  🎉 DONE! Your app is running!

  Change App Name
  ───────────────
    1. Open: app/src/main/res/values/strings.xml
    2. Change: <string name="app_name">Your Name</string>
    3. Build → Rebuild Project


  Change App Icon
  ───────────────
    1. Right-click: app/src/main/res/
    2. New → Image Asset
    3. Upload your icon
    4. Click: Next → Finish
    5. Build → Rebuild Project


  Change App Description
  ──────────────────────
    1. Open: app/src/main/res/values/strings.xml
    2. Edit: app_description string
    3. Build → Rebuild Project


  Test on Physical Device
  ───────────────────────
    1. Connect device via USB cable
    2. Enable Developer Mode:
       • Settings → About Phone
       • Tap "Build Number" 7 times
       • Go to Settings → Developer Options
       • Enable "USB Debugging"
    3. In Android Studio: Run → Run 'app'
    4. Select your device
    5. Click OK
    6. App installs and runs automatically


  Build for Play Store
  ────────────────────
    1. Build → Generate Signed Bundle / APK
    2. Select "Android App Bundle"
    3. Create new keystore (save it safely!)
    4. Fill in your details
    5. Next → Finish
    6. Bundle ready in: app/build/outputs/bundle/release/
    7. Upload to Google Play Console

┌─────────────────────────────────────────────────────────────────────────────┐
│  🆘 TROUBLESHOOTING                                                         │
└─────────────────────────────────────────────────────────────────────────────┘

  "Gradle sync failed"
  ───────────────────
    → File → Project Structure
    → SDK Location
    → Ensure Android SDK API 34 is installed
    → Click OK
    → Sync again


  "Cannot find JDK"
  ────────────────
    → File → Project Structure
    → SDK Location
    → Set "Gradle JDK" to Java 11 or higher
    → Click OK
    → Sync again


  "Gradle sync takes forever"
  ──────────────────────────
    → File → Invalidate Caches / Restart
    → Invalidate and Restart
    → Wait 5-10 minutes


  "Cannot find Android SDK"
  ─────────────────────────
    → Open Android Studio
    → Tools → Device Manager
    → This will start SDK setup if missing
    → Follow on-screen instructions


  "App won't build"
  ────────────────
    → Build → Clean Project
    → Build → Rebuild Project


  "App crashes on startup"
  ───────────────────────
    → Settings → Apps → Let's Math
    → Storage → Clear Data
    → Reinstall app


  "Device not recognized"
  ──────────────────────
    → Connect device
    → Settings → About → Build Number (tap 7 times)
    → Settings → Developer Options → USB Debugging ON
    → Unplug and plug in USB again
    → Try again
