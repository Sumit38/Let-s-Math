🚀 3-STEP START (Takes 10 minutes)
════════════════════════════════════════════════════════════════════════════════

STEP 1: Open in Android Studio
────────────────────────────────

1. Open Android Studio
2. Click: File → Open
3. Select: LetsMatApp_NATIVE folder
4. Click "Open"


STEP 2: Wait for Gradle Sync
─────────────────────────────

• Look at bottom right
• You'll see progress bars
• WAIT until: "Gradle sync finished" ✓
• Takes 2-5 minutes


STEP 3: Build APK
──────────────────

1. Click: Build (top menu)
2. Click: Build Bundle(s) / APK(s)
3. Click: Build APK(s)
4. WAIT for: "BUILD SUCCESSFUL" ✓
5. Takes 2-5 minutes


✅ YOUR APK IS READY!
Location:
LetsMatApp_NATIVE\app\build\outputs\apk\debug\app-debug.apk


📱 INSTALL & TEST
════════════════════════════════════════════════════════════════════════════════

Option A: On Your Phone (FASTEST)
──────────────────────────────────

1. Connect phone via USB
2. On phone: Settings → About Phone → tap "Build Number" 7 times
3. Go back: Settings → Developer Options → USB Debugging ON
4. In Android Studio: Run → Run 'app'
5. Select your phone → Click OK
6. App installs and opens immediately! ✓


Option B: Copy APK to Phone
───────────────────────────

1. Find APK at: app/build/outputs/apk/debug/app-debug.apk
2. Email or copy to phone
3. Tap APK → Install
4. Open from home screen
