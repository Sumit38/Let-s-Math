📱 TESTING THE APP
════════════════════════════════════════════════════════════════════════════════

  Option A: Physical Device (Recommended - Fastest)
  ───────────────────────────────────────────────

    1. Connect phone via USB cable
    2. Enable USB Debugging on phone:
       • Settings → About Phone
       • Tap "Build Number" 7 times
       • Go back to Settings → Developer Options
       • Enable "USB Debugging"
    3. In Android Studio: Run → Run 'app'
    4. Select your phone
    5. Click OK
    6. App installs and opens automatically


  Option B: Android Emulator (from Android Studio)
  ──────────────────────────────────────────────

    1. In Android Studio: Run → Run 'app'
    2. Select an Android Virtual Device
    3. If none exist:
       • Click "Create New Virtual Device"
       • Choose device (Pixel 4 recommended)
       • Choose Android version (14 recommended)
       • Finish
    4. Run → Run 'app' again
    5. Select the emulator
    6. Click OK
    7. Wait for emulator to boot and app to run


  Option C: Transfer APK File to Phone
  ───────────────────────────────────

    1. Build APK (see Quick Start above)
    2. Email APK file to yourself
    3. Open email on phone
    4. Download attachment
    5. Tap file to install
    6. Open app from home screen

🆘 COMMON ISSUES & FIXES
════════════════════════════════════════════════════════════════════════════════

  Issue: Gradle sync fails
  Fix:
    • File → Project Structure
    • Go to SDK Location
    • Ensure Java and Android SDK are set correctly
    • Click OK
    • Try again


  Issue: "Cannot find Android SDK"
  Fix:
    • Tools → Device Manager
    • This will trigger Android SDK installation
    • Install API 34 when prompted


  Issue: Build fails
  Fix:
    • Build → Clean Project
    • Build → Rebuild Project


  Issue: App won't install on phone
  Fix:
    • Phone must be Android 5.0 or higher
    • Enable "Unknown Sources" in phone Settings
    • Try again


  Issue: App crashes when opening
  Fix:
    • Phone Settings → Apps → Let's Math
    • Storage → Clear Data
    • Reinstall app


  More help → See LetsMatApp/IMPORT_GUIDE.txt


🎓 PUBLISHING TO GOOGLE PLAY STORE
════════════════════════════════════════════════════════════════════════════════

  1. Create an account
     → Go to: https://play.google.com/console
     → Sign in with Google Account
     → Pay $25 one-time developer fee


  2. Create an app
     → Click "Create new app"
     → Fill in app name and type


  3. Build Release App Bundle
     → Build → Generate Signed Bundle / APK
     → Select "Android App Bundle"
     → Create keystore (SAVE THE PASSWORD!)
     → Build ready in: app/build/outputs/bundle/release/


  4. Upload to Play Store
     → Release → Create new release
     → Upload AAB file


  5. Fill in app details
     → Description
     → Screenshots
     → Category
     → Privacy policy


  6. Set pricing & country
     → Free or Paid
     → Select countries


  7. Publish
     → Fill content rating form
     → Review everything
     → Click "Publish"


  🎉 Your app is now on Google Play Store!
